# جعل الثيم الداكن هو الافتراضي

- الثيم الداكن هو المظهر الافتراضي عند التثبيت الجديد.
- خيار «افتراضي» يستخدم الثيم الداكن أيضًا.
- خيار «فاتح» يبقى متاحًا لمن يختاره يدويًا.
- تم تحديث ألوان خلفية الإعدادات والبطاقات والحوار لتتوافق مع الاختيار.

ملاحظة: لم يتم إجراء بناء Flutter فعلي في هذه البيئة.
