# تحديث قصص وإعجابات بلوساب

- تصغير شريط القصص إلى ارتفاع 88 بكسل مع دوائر أصغر وتنسيق أفقي قريب من واتساب لتوفير مساحة من الشاشة.
- تسمية دائرة صاحب الحساب «حالتي»، ووضعها أولاً، ثم قصص بقية المستخدمين.
- إضافة زر إعجاب ❤️ سريع في أسفل واجهة المحادثة، ويرسل القلب كرسالة عادية متوافقة مع نظام الرسائل الحالي.
- إضافة زر إعجاب في عارض القصص وحفظ حالة الإعجاب محلياً لكل قصة.
- دعم استقبال حزمة `story_like` وإظهار إشعار نظام لصاحب القصة عند وصولها، مع إزالة تكرار الإشعار لنفس القصة والمستخدم.

ملاحظة: إشعارات الإعجاب بين هاتفين تعتمد على وصول حزمة الإعجاب عبر البلوتوث أو شبكة Wi-Fi المحلية. كما أن القصص نفسها في النسخة الحالية تُحفظ محلياً؛ مزامنة القصص ووسائطها بين أجهزة المستخدمين ليست نظام نشر سحابياً، لذا يجب أن تكون القصة متاحة على الجهاز المستقبل حتى تعمل التجربة كاملة بين الطرفين.
