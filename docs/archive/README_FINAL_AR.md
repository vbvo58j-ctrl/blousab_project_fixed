# بلوساب — النسخة النهائية للمراجعة والاستيراد

## مصدر النسخة
- النسخة المرجعية: `الجديد14.zip` (لم يتم الكتابة فوقها أو تعديلها).
- بُنيت هذه النسخة من نسخة العمل المستخرجة من الأرشيف المرجعي، مع الاحتفاظ بملفات المشروع الأصلية وإضافة تعديل إعداد Flutter SDK الموثق أدناه.
- تم تجنب دمج مشاريع مرحلية قديمة بشكل أعمى، لأن ذلك قد يستبدل ملفات أحدث أو يزيل تغييرات غير متوافقة.

## التعديل البرمجي المطبق
- `android/settings.gradle`: قراءة `flutter.sdk` من `android/local.properties` عند وجوده، ثم تجربة متغير البيئة `FLUTTER_ROOT` إذا كانت القيمة مفقودة أو فارغة، وإظهار رسالة واضحة إذا لم يُحدد أي مسار.
- لم تُضف مسارات SDK خاصة بجهاز بعينه إلى المشروع.

## التحقق الذي نُفذ فعليًا
- فحص سلامة أرشيف المصدر والنسخة النهائية بواسطة اختبار ZIP.
- فحص بنية ملفات XML في المشروع.
- مقارنة الملفات مع `الجديد14.zip`: التغيير البرمجي مقصور على `android/settings.gradle`؛ أضيفت وثائق الفحص وقبول النسخة.
- لم تتوفر أدوات Flutter وDart في بيئة العمل، ولذلك لم ينفذ `flutter pub get` أو `flutter analyze` أو `flutter test` أو `gradle assemble`، ولم يُنتج APK.
- لم تُجرَ اختبارات فعلية بين أجهزة Android أو مراجعة بصرية مباشرة لكل شاشة؛ لا تعتبر هذه الوظائف مختبرة لمجرد وجود ملفاتها.

## الاستيراد والبناء على جهاز مطور
1. فك ضغط الأرشيف إلى مجلد مستقل.
2. ثبّت Flutter SDK وAndroid SDK المتوافقين مع إعدادات المشروع.
3. عيّن `flutter.sdk` داخل `android/local.properties` أو عيّن `FLUTTER_ROOT` إلى مجلد Flutter.
4. من جذر المشروع نفّذ `flutter pub get`، ثم `flutter analyze` و`flutter test`، ثم `flutter build apk`.
5. عالج أي أخطاء تظهر وسجّل مخرجات الأوامر قبل اعتبار البناء ناجحًا.

## معيار الحالة
هذه نسخة مشروع قابلة للفحص والاستيراد، وليست شهادة بناء ناجح. حالة البناء والاختبارات على الأجهزة: **غير مؤكدة حتى تنفيذها في بيئة Flutter/Android فعلية**.
