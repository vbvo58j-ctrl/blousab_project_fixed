# الجزء التالي: إعجاب الحالات وتفعيل إشعارات النشاط الاجتماعي

## التعديلات
- زر إعجاب الحالات موجود في عارض الحالة؛ وتم الإبقاء عليه. يحفظ الإعجاب محليًا ويرسل حزمة `story_like` عبر وسائل الاتصال الموجودة بالمشروع.
- طلب إذن إشعارات Android عند بدء التطبيق بعد تهيئة خدمة الإشعارات.
- إضافة إشعارات نظام منفصلة للنشاط الاجتماعي: طلبات الصداقة، إعجابات الحالات، وإعجابات/تعليقات المنشورات عند وصول الحزم المناسبة.
- فصل قناة النشاط الاجتماعي `blousab_social` عن قناة رسائل المحادثات `blousab_messages`؛ لا تُحوّل رسائل الدردشة إلى إشعارات اجتماعية.
- إرسال حزمة نشاط اجتماعي عند الإعجاب بمنشور أو إضافة تعليق، مع معرف حدث لتقليل التكرار.
- توضيح وصف أيقونة الإشعارات العلوية بأنها خاصة بالمنشورات والحالات والتفاعلات وطلبات الصداقة.

## حدود التحقق
- فحص سلامة ZIP فقط.
- لم يُشغّل `flutter pub get` أو `flutter analyze` أو بناء APK؛ Flutter/Dart غير متوفرين في بيئة الإنشاء.
- لم تُختبر الإشعارات بين جهازين فعليين. وصول الإشعارات يعتمد على تشغيل التطبيق/مستمع الاتصال، الأذونات، وإمكانية وصول الحزم عبر التقنية المستخدمة.
- نافذة أيقونة الإشعارات داخل صفحة المنشورات ما زالت تعرض طلبات الصداقة فقط؛ إشعارات إعجابات الحالات والمنشورات تذهب عبر إشعارات Android. توحيد جميع الأنشطة داخل قائمة الأيقونة يحتاج إلى سجل إشعارات داخل التطبيق في خطوة لاحقة.
