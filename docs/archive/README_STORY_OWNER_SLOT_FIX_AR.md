# إصلاح ترتيب قصص بلوساب

- حالة الجهاز الحالي تظهر في خانة «قصتك» الأولى فقط.
- عند وجود حالة شخصية، يظهر إطار دائري بألوان بلوساب (التركوازي والأخضر والذهبي) حول الصورة الشخصية.
- الضغط على الصورة يفتح أحدث حالة شخصية، وزر (+) يظل مخصصًا لإضافة حالة جديدة.
- الحالات التي لا تخص المستخدم الحالي فقط هي التي تظهر بعد خانة «قصتك».
- تمت المحافظة على مفاتيح التخزين الحالية حتى لا تضيع الحالات المحفوظة على الجهاز.

ملاحظة: هذه النسخة تصلح فصل العرض محليًا؛ ظهور حالات أشخاص آخرين من أجهزة مختلفة ما زال يتطلب مزامنة/خادمًا أو نقلًا بين الأجهزة.
