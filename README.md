# بلوساب (Blousab)

تطبيق Flutter لأندرويد للتواصل مع من حولك **دون إنترنت**: محادثات خاصة ومجتمعات بموافقة المنشئ،
عبر البلوتوث الكلاسيكي (RFCOMM) والشبكة المحلية (Wi-Fi / نقطة اتصال)، مع ترحيل متعدد القفزات.

## ما الجديد في 1.1.0
انظر `CHANGELOG_AR.md`. باختصار: هوية تشفيرية وتوقيع كل حزمة، تشفير رسائل المجتمعات والمحادثات الخاصة،
إقرار تسليم (✓✓)، ترحيل ذكي بتبادل القوائم، خدمة خلفية، SQLite للرسائل، قفل PIN مجزّأ، حدود أمان على الأحجام.

> **تنبيه توافق:** البروتوكول تغيّر (كل حزمة موقّعة). الإصدارات القديمة لا تتبادل الرسائل مع 1.1.0.

## البناء
```
flutter pub get
flutter analyze
flutter test
flutter build apk --release
```
* ضع `flutter.sdk` في `android/local.properties` أو عرّف `FLUTTER_ROOT`.
* للنشر أنشئ `android/key.properties` (storeFile, storePassword, keyAlias, keyPassword).
  دونه يُوقَّع release بمفتاح debug **للتجربة فقط**.
* CI: `.github/workflows/main.yml` (تحليل + اختبارات + بناء، ويدعم أسرار التوقيع).

## الوثائق
| الملف | المحتوى |
|---|---|
| `docs/ARCHITECTURE_AR.md` | بنية الكود والخدمات وتدفق الرسائل |
| `docs/SECURITY_AR.md` | البروتوكول، نموذج التهديد، الضمانات والحدود |
| `docs/ACCEPTANCE_CHECKLIST_AR.md` | قائمة اختبار يدوي على أجهزة حقيقية |
| `CHANGELOG_AR.md` | سجل التغييرات |
| `docs/archive/` | وثائق المراحل السابقة (للمرجع التاريخي) |

## حالة التحقق
لم يُبنَ هذا الإصدار ولم تُشغَّل اختباراته في بيئة التطوير التي كُتب فيها (لا Flutter SDK). الكود مراجَع
يدويًا ويتضمن اختبارات وحدات في `test/` **لم تُنفَّذ بعد**. شغّل `flutter analyze && flutter test` أولًا
وأصلح أي خطأ تجميع قبل أي اختبار على الأجهزة.
